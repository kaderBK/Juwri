Notification sounds (assets/global/audio). Every playable file here shows up in the owner's sound
picker (notification_sound_library() in core/app/Http/Helpers/Helper.php), id = file name.

1. Own sounds (juwri, generated; no third-party content)
   call-waiter.mp3, message.mp3, message.ogg
   The file names are kept so stores that picked them keep a working sound. Generated with ffmpeg (sine partials with exponential decay):

   MSG="0.32*(sin(2*PI*1318.5*t)+0.35*sin(2*PI*2637*t))*exp(-6*t)*lt(t,0.9)+0.32*(sin(2*PI*1760*(t-0.16))+0.35*sin(2*PI*3520*(t-0.16)))*exp(-5*(t-0.16))*gte(t,0.16)"
   CW="0.3*(sin(2*PI*784*t)+0.4*sin(2*PI*1568*t))*exp(-4*t)+0.3*(sin(2*PI*659.3*(t-0.45))+0.4*sin(2*PI*1318.5*(t-0.45)))*exp(-4*(t-0.45))*gte(t,0.45)+0.3*(sin(2*PI*784*(t-1.2))+0.4*sin(2*PI*1568*(t-1.2)))*exp(-4*(t-1.2))*gte(t,1.2)+0.3*(sin(2*PI*659.3*(t-1.65))+0.4*sin(2*PI*1318.5*(t-1.65)))*exp(-4*(t-1.65))*gte(t,1.65)"
   ffmpeg -f lavfi -i "aevalsrc='$MSG|$MSG':s=44100:d=1.2" -af "afade=t=out:st=1.0:d=0.2" -c:a libmp3lame -b:a 128k -map_metadata -1 message.mp3
   ffmpeg -f lavfi -i "aevalsrc='$MSG|$MSG':s=44100:d=1.2" -af "afade=t=out:st=1.0:d=0.2" -c:a vorbis -strict experimental -ac 2 -map_metadata -1 message.ogg
   ffmpeg -f lavfi -i "aevalsrc='$CW|$CW':s=44100:d=2.8" -af "afade=t=out:st=2.4:d=0.4" -c:a libmp3lame -b:a 128k -map_metadata -1 call-waiter.mp3

2. Own sounds (juwri, generated; no third-party content) - the other 21 files
   notification_message-notification-alert-7-331719.mp3, universfield-*.mp3 (20 files)
   Replaced in WI-05f: the previous files with these names came from a third-party sound pack
   under a non-OSI licence. The names are kept only so stored settings ids and the five defaults
   (order_new, order_ready, review, dispute, waitlist in notification_sounds_defaults()) keep
   working; the words and numbers in them no longer mean anything.
   Generated by generate-sounds.py in this folder (Python standard library renders sine
   partials with a short attack and exponential decay to WAV; ffmpeg/libmp3lame encodes 96 kbps
   mono MP3 with metadata stripped). Deterministic: `python3 generate-sounds.py` rewrites the
   same 21 files. The defaults are short, distinct chimes:
     order_new    notification_message-notification-alert-7-331719.mp3  rising 4-note bell arpeggio
     review       universfield-new-notification-036-485897.mp3          soft marimba falling fourth
     order_ready  universfield-new-notification-061-494263.mp3          glassy rising fifth
     (dispute uses the same file as order_ready, as before)
     waitlist     universfield-new-notification-066-494545.mp3          single upward "bubble" glide
   The ringtone-* files are two-phrase melodies, each with its own melody, timbre and tempo.
